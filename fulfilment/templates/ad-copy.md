## Upload Instructions

**Google Ads:**
1. Log in to ads.google.com with client's Google account (or create one).
2. New Campaign → Search → Leads.
3. Paste keywords and ad copy from above. Set daily budget: £5–10 to start.
4. Geographic target: {{ town }} + {{ radius }} miles. Language: English.

**Meta Ads:**
1. Log in to business.facebook.com → Ads Manager.
2. Create → Traffic or Lead Generation campaign.
3. Ad set: location targeting as above.
4. Upload approved image. Paste copy. Set £3–5/day budget.
5. Monitor frequency — if >3, pause and refresh creative.
